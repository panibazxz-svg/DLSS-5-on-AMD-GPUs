# [DLSS-5-on-AMD-GPUs](https://benchmarksetups.com/dlss-5-on-amd-gpu/)
DLSS 5 on AMD GPUs: Mod Compatibility, Performance, and Limitations
DLSS 5 on AMD GPU Someone got Nvidia’s DLSS 5 running on an AMD graphics card. It works. It’s also barely playable.

In a project titled DLSS-NR-on-AMD, a modder going by the handle danielblnc loads Nvidia’s neural rendering DLL onto RDNA 4 hardware, such as the RX 9070 XT. Cyberpunk 2077 ran at less than 20 frames per second in 1080p on the initial build. A few days later, a patch increased that to 30 frames per second. The hack still has a long way to go before it becomes the parity project that people are referring to, as Nvidia’s own RTX 5070 Ti runs the same workload well beyond that.
